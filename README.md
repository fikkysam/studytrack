# StudyTrack — Student Assignment and Deadline Tracker

## Project Overview
StudyTrack is a browser-based application designed to help students manage assignments, priorities, and deadlines in one place.

## Sprint 1 Features
- Add assignments with a title, course, due date, and priority
- View assignments in a list
- Mark assignments as complete or incomplete
- Delete assignments
- Save assignment data using browser localStorage
- Display total, pending, and completed assignment counts

## Technologies
- HTML
- CSS
- JavaScript
- Browser localStorage
- GitHub
- AWS Amplify Hosting

## How to Run
1. Open `index.html` in a browser, or use the VS Code Live Server extension.
2. Add and manage assignments.

## Scope and Limitations
Assignment data is stored in the current browser on the current device. The application does not include user accounts, a backend API, or cross-device synchronization.
